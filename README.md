# OIBSIP_PythonProgramming_Task2

## BMI Calculator Using Python

### 📌 Objective

The objective of this project is to create a Body Mass Index (BMI) calculator using Python. It helps users determine whether their body weight is underweight, normal, overweight, or obese based on their height and weight.

### 🛠 Technologies Used

* Python
* Basic Python Functions
* Input/Output Operations

### 📂 Project Description

This project calculates the Body Mass Index (BMI) using the user's weight and height. The program then classifies the BMI into different health categories.

### ⚙️ Steps Performed

1. Took input from the user for weight and height.
2. Applied the BMI formula.
3. Calculated the BMI value.
4. Displayed the BMI category based on the result.

### 📊 BMI Formula

BMI = Weight (kg) / Height² (m)

### ▶️ How to Run the Project

1. Install Python on your system.
2. Download or clone the repository.
3. Run the Python file:

```
python bmi_calculator.py
```

4. Enter your weight and height when prompted.

### 📌 Output

The program calculates the BMI value and displays the health category.

Example:

```
Enter your weight (kg): 70
Enter your height (m): 1.75

Your BMI is: 22.86
Category: Normal weight
```
